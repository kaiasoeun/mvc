
[MVC] - 규모가 클때 (엔터프라이즈 급)
1. 정의 - Model, View, Controller를 의미
2. 의미 - 개발 방법론을 의미
			개발패턴이라고함
			
3. mvc 을 적용해야하는 이유
 - 애플리케이션 개발시 디자인(view-사용자에게 보여지는 영역)과 로직(업무를 반영한 모델)은 분리시켜야 유지보수성이 높아짐 (효율성과 비용문제와 직결되므로)
 
Model - 로직
View - 디자인
Controller - 디자인과 로직을 분리시켜주는 영역 
-----------------------------------------------
javaEE 분야는 대규모의 기업용 애플리케이션을 개발하는 플랫폼이므로 MVC를 준수하여 개발을 함
이때 javaEE 기술로 디자인과 로직을 분리시켜 개발하는 방법을 가리켜 model2라 부른다 

model2를 MVC로 개발할때는 다음과 같이: 

Model - 순수 java로 구현
View - jsp 로 구현
Controller - 서버 측에서 실행될수 있는 servlet 클래스
